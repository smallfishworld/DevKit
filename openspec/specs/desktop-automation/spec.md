# Desktop automation

## Purpose

面向嵌入式开发重复 GUI 流程的本地键鼠录制、编辑、回放和宏库管理。

### Requirement: 全局事件录制

录制器 MUST 支持跨应用收集键盘及鼠标事件、顺序和相对延时，并明确录制状态。

#### Scenario: 录制流程

- **WHEN** 用户用录制热键启动、操作目标软件、再停止录制
- **THEN** 事件和相对时间信息写入可编辑的本地宏。

### Requirement: 事件编辑

宏编辑器 MUST 支持修改和启停步骤、调整延时及插入文本、等待颜色等动作。

#### Scenario: 设备响应等待

- **WHEN** 用户在宏中增加等待指定像素颜色出现的步骤
- **THEN** 回放在条件满足后继续，超时则按失败处理。

### Requirement: 可控回放

回放器 MUST 支持变速、循环和随时触发的紧急停止，并在停止后释放仍按下的输入状态。

#### Scenario: 紧急停止

- **WHEN** 用户在循环宏执行时按急停热键
- **THEN** 宏停止且输入不会保持为卡键状态。

### Requirement: 宏库管理

宏库 MUST 支持本地 JSON 保存、导入导出、分组及单个宏的热键绑定。

#### Scenario: 迁移宏

- **WHEN** 用户导出宏并在其他设备导入
- **THEN** 回放步骤和顺序保持一致。

### Requirement: 敏感信息警示

用户界面或文档 MUST 提醒键鼠录制可能保留密码等敏感输入。

#### Scenario: 启用录制

- **WHEN** 用户准备录制全局键盘事件
- **THEN** 可看到不要在录制过程中输入密码的提示。

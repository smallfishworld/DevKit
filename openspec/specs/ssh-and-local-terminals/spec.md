# SSH and local terminals

## Purpose

描述 SSH 及本地 PTY 终端的连接、终端仿真、磁盘历史、输入和流控。 用户可以交互输入、查看持续输出与历史日志、调整终端尺寸，并在连接断开后正确释放资源。

## Requirements

### Requirement: SSH 连接

SSH 面板 MUST 支持主机、端口、用户凭据以及受支持的密码和私钥认证。

#### Scenario: 建立连接

- **WHEN** 用户输入正确的 SSH 认证参数
- **THEN** 终端连接后能够交互发送和接收文本。

### Requirement: 标准终端语义

SSH 和本地终端 MUST 提供 VT/ANSI 控制、彩色回滚、复制/粘贴、搜索、字体和窗口尺寸同步。

#### Scenario: 全屏命令

- **WHEN** 用户在 SSH 中运行 vim 或 top 并调整面板大小
- **THEN** 终端尺寸变化传送给远端 PTY，布局能够响应。

### Requirement: 磁盘日志

SSH 和本地终端 MUST 为会话提供可查询及导出的磁盘历史，并限制分页查询大小。

#### Scenario: 查找以前输出

- **WHEN** 会话积累大量打印后用户搜索关键词
- **THEN** 可以按页读取命中结果，无需全量读到渲染内存。

### Requirement: 输出与关闭安全

终端输出 MUST 依 ACK 追踪已显示帧、限制积压；断开或销毁面板 MUST 释放会话资源。

#### Scenario: 网络断开

- **WHEN** 正在输出的 SSH 会话异常关闭
- **THEN** 停止传输、释放资源并保留应保留的已写入日志。

### Requirement: SSH 会话预设

SSH 面板 MUST 把「已存会话」作为连接参数预设放在顶部工具栏，侧栏只放快捷命令。用户 MUST 能在工具栏内套用预设、把当前填写的参数存为预设（同名覆盖）以及删除预设，且套用预设 MUST NOT 自动发起连接。

#### Scenario: 保存并套用预设

- **WHEN** 用户填写主机、端口与凭据后点击「存为预设」并命名（或直接接受「用户名@主机」默认名），随后在预设下拉中选择它
- **THEN** 表单回填该预设的主机、端口与凭据，连接仍由用户点击连接按钮触发。

#### Scenario: 删除预设

- **WHEN** 用户在工具栏中选中预设并点击删除
- **THEN** 按钮就地变为「确认」，再点击一次才删除该预设；当前表单内容保持不变。

#### Scenario: 没有主机时不存预设

- **WHEN** 用户在未填写主机时点击「存为预设」
- **THEN** 界面提示先填写主机，不会创建空预设。

### Requirement: 认证信息风险

持久化 SSH 凭据时 MUST 让用户知道保存敏感信息的风险。

#### Scenario: 保存密码

- **WHEN** 用户选择保存含密码的 SSH 预设
- **THEN** 侧栏明确提示预设里的密码可能以明文留在本地 config.json，不用于生产环境凭据。

### Requirement: 远程与本地终端的显示设置入口

SSH 和本地终端 MUST 在输出工具栏中提供可点击的显示设置入口。

#### Scenario: 调整终端字体

- **WHEN** 用户在 SSH 或本地终端打开显示设置并调整字号
- **THEN** 当前终端应用新字号，连接或 Shell 进程仍可继续运行。

### Requirement: SSH 会话接入设备插件

SSH 服务 MUST 实现 `StreamSessionBridge`（`transport: 'ssh'`），SSH 面板工具栏 MUST 提供设备插件入口，支持将声明 `ssh` 传输能力的插件实例绑定到当前已连接会话，并在断开连接时自动解除绑定与释放写入租约。

#### Scenario: 在 SSH 会话运行插件动作

- **WHEN** 用户连接 SSH 后在工具栏绑定支持 `ssh` 的插件并触发动作或自动应答
- **THEN** 插件通过受控 `ctx.stream` 读写当前 SSH 通道，断开 SSH 后插件自动停止且不再写入。

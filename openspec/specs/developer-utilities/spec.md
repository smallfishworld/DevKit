# Developer utilities

## Purpose

提供常用嵌入式工程工具，包含计算、编码、大小端、文本/文件比较、时间戳和取色。 这些工具必须提供可核对的输入与输出体验，并在处理大量比较结果时避免无限制渲染拖慢界面。

## Requirements

### Requirement: 程序员计算器

计算器 MUST 支持 HEX/DEC/OCT/BIN 多进制、8/16/32/64 位宽与位运算，并提供可点击的位编辑视图。

#### Scenario: 位操作

- **WHEN** 用户切换位宽并点击某个位
- **THEN** 数字和各进制显示同步更新。

### Requirement: 编码及大小端转换

转换工具 MUST 支持既定文本编码、Base64/URL 与多字节大小端解释，并保留输入供用户复制。

#### Scenario: 查看数据

- **WHEN** 用户输入一段 UTF-8/GBK 文本或十六进制字节序列
- **THEN** 可获得对应编码或 LE/BE 解释结果。

### Requirement: 时间戳转换

时间戳工具 MUST 识别秒、毫秒、微秒、纳秒及常见十六进制时间输入。

#### Scenario: 解析时间戳

- **WHEN** 用户粘贴毫秒级 Unix 时间戳
- **THEN** 显示对应可读日期时间及其他单位。

### Requirement: 比较工具

Diff 工具 MUST 支持文本、十六进制和文件夹比较，并在结果过大时限制渲染。

#### Scenario: 大型差异

- **WHEN** 用户比较较大文件并超过界面安全展示阈值
- **THEN** 界面给出截断或受限展示提示而非无限渲染。

### Requirement: 取色与坐标

取色器 MUST 支持屏幕像素取色和坐标拾取，并允许复制结果。

#### Scenario: 采样屏幕

- **WHEN** 用户通过截屏点选像素
- **THEN** 显示并可复制颜色值或位置。

### Requirement: 转换工具工作区

时间戳工作区 MUST 提供可暂停的实时时钟与双向转换区。大小端工作区 MUST 提供字节序列表、位宽筛选以及数值编码与翻转区。

#### Scenario: 暂停时钟并转换

- **WHEN** 用户暂停实时时钟并填入时间戳
- **THEN** 时钟读数保持不变，输入仍可转换，结果可直接复制。

#### Scenario: 筛选字节序的位宽

- **WHEN** 用户选择 32 位并启用详细值
- **THEN** 工作区显示对应的大端和小端解释及 Float32 结果。

#### Scenario: 编码负数

- **WHEN** 用户输入负整数查看数值的大小端字节
- **THEN** 16、32、64 位分别显示补码的 LE/BE 字节，超出相应位宽时注明保留低位。

#### Scenario: 带毫秒的日期反查

- **WHEN** 用户按本地时区或 UTC 输入日期并填写毫秒
- **THEN** 反查结果保留毫秒，传入正向解析工具时仍表示同一时刻。

## ADDED Requirements

### Requirement: 统一应用标识

工作台 MUST 使用用户确认的 B「模块核心」青绿标识作为统一应用标识。标题栏、Windows 应用图标及运行时窗口图标 MUST 保持相同的模块形状与主色关系；各尺寸资源 MUST 从同一可编辑 SVG 母版派生。

#### Scenario: 深浅主题标题栏与版本入口

- **WHEN** 用户在深色或浅色主题下打开工作台，并点击标题栏的 DevKit 标识入口
- **THEN** 标题栏清晰显示青绿模块核心标识与 DevKit 名称，原版本信息浮层仍可打开并展示应用及运行时版本，标题栏的导航和窗口控制保持可用。

#### Scenario: Windows 打包与运行时图标一致

- **WHEN** 用户查看本次 Windows 打包的 DevKit 可执行文件并启动应用
- **THEN** 可执行文件图标与运行时任务栏图标均使用同一 B「模块核心」设计，应用所需的运行时图片随包提供，且 Windows 应用身份保持为 `com.embedded.devkit`。

#### Scenario: 单源派生小尺寸资源

- **WHEN** 维护者从确认后的 SVG 母版重新生成应用图标资源
- **THEN** 界面标识、单色备用标识、应用 PNG 和多尺寸 Windows ICO 保持同一核心形状；ICO 包含 16、20、24、32 像素等小尺寸档位，缩小时仍能辨认模块结构与中空区域，生成结果可检查是否与母版一致。

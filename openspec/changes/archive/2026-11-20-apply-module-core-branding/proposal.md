## Why

用户已确认最初的 B「模块核心」青绿图标，需要把同一标识应用到工作台与应用分发产物，避免标题栏、可执行文件和运行中的窗口出现不同标识。

## What Changes

- 以可编辑 SVG 母版生成界面标识、单色备用、应用 PNG 和多尺寸 Windows ICO。
- 标题栏采用该标识并保留原版本信息入口；Windows 打包图标、运行时窗口图标与现有应用身份统一。
- 记录资源派生与打包检查入口，保持现有导航、主题、工具和会话行为。

## Scope and Status

- 影响的现行能力：`workbench`；同步 `openspec/specs/workbench/spec.md` 的「统一应用标识」要求。
- 资产与界面、主进程及打包接入已实现；本轮类型检查、完整单测、UI 冒烟与 CI 验证仍待确认。
- 范围限于应用标识，不扩展工作台版式、托盘或发布流程；macOS/Linux 图标配置不代表已完成对应平台实测。

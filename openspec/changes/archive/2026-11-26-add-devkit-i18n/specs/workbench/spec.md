## ADDED Requirements

### Requirement: 应用语言实时切换与持久化

工作台 MUST 在设置中提供 `简体中文（zh-CN）` 与 `English（en）` 两种应用语言，MUST 在没有有效偏好时默认使用中文，并 MUST 持久化用户选择。切换语言 MUST 就地更新已显示的 DevKit 自有界面，不得刷新工作台、重建工具面板、改变 `panelId`，也不得中断已有连接、传输、终端缓冲或未提交输入。

#### Scenario: 首次启动默认中文

- **WHEN** 用户首次启动应用，或已保存的语言偏好缺失或无效
- **THEN** 工作台从首次可交互画面起使用简体中文，且全部工具仍可正常打开。

#### Scenario: 实时切换为英文

- **WHEN** 用户在设置中把语言从简体中文切换为 English
- **THEN** 当前工作台、已打开的内置工具及可更新的 DevKit 自有窗口就地显示英文；之后打开的 DevKit 原生文案使用英文，无需重载或重启应用。

#### Scenario: 切换语言不打断会话

- **WHEN** 用户在串口、SSH、本地终端、网络或传输会话运行期间切换语言
- **THEN** 连接与任务继续运行，终端缓冲、面板输入、标签顺序和 `panelId` 保持不变，只有应用自有展示文案改变。

#### Scenario: 重启恢复语言偏好

- **WHEN** 用户选择 English 后正常退出并重新启动 DevKit
- **THEN** 首次可交互画面直接使用英文；再次选择简体中文并重启时同样恢复中文。

### Requirement: DevKit 自有文案完整本地化与数据边界

DevKit MUST 为应用壳、设置、全部内置工具及应用创建的原生窗口、菜单、对话框、通知和错误说明提供完整的 `zh-CN` 与 `en` 文案。两种语言目录 MUST 使用一致的消息键并支持动态参数。应用 MUST 将终端输出、设备/网络/传输数据、文件和日志载荷、用户输入、插件内容、第三方页面及外部程序输出保持原样，不得为了界面本地化而翻译或改写这些数据。

#### Scenario: 浏览全部内置工具

- **WHEN** 用户选择任一支持语言并依次打开工具箱中的全部 DevKit 内置工具及其设置、确认、空态和错误状态
- **THEN** 工具名称、说明、控件、状态与应用自有提示均使用所选语言，不正常暴露内部消息键或混入另一语言的应用自有文案。

#### Scenario: 打开应用自有原生界面

- **WHEN** 用户在所选语言下触发 DevKit 创建的辅助窗口、认证窗口、更新窗口、原生菜单、对话框、通知或错误说明
- **THEN** 其中由 DevKit 提供的文案使用所选语言；操作系统通用控件和第三方页面不被宣称为 DevKit 翻译范围。

#### Scenario: 设备和远端数据保持原样

- **WHEN** 当前语言为 English，而终端、串口、设备、网络、文件、日志、插件或第三方页面包含中文或任意原始字节内容
- **THEN** DevKit 按原有编码和展示规则传递该内容，不翻译、不替换，也不因 locale 改变协议数据。

#### Scenario: 本地化资源不完整

- **WHEN** 运行时无法解析某个应用自有消息键或已保存 locale 无效
- **THEN** 应用安全回退中文并保留可诊断信息，工具操作和现有会话继续可用；目录一致性测试在发布前报告缺失或空白译文。

### Requirement: 双语 README 与 Release 内容兼容

仓库 MUST 提供内容完整的中文 `README.md` 与英文 `README.en.md`，并在两者的显眼位置互相链接。同一 GitHub Release 的说明 MUST 同时包含中文与 English 章节，MUST 只包含一张供两种语言共用的双语下载表，并 MUST 精确保留 `## 下载` 标题和稳定附件名以兼容已部署的更新读取器。发布 CI MUST 只更新唯一 marker 对限定的下载表区段；应用内更新界面 MUST 同时展示该 Release 的中文与 English 章节。

#### Scenario: 从任一 README 切换语言

- **WHEN** 用户打开 `README.md` 或 `README.en.md`
- **THEN** 当前文档可独立提供完整的安装、使用、开发与发布信息，并在顶部通过明确链接打开另一语言版本。

#### Scenario: 查看双语 Release

- **WHEN** 维护者发布一个包含本次约定的 GitHub Release
- **THEN** 同一发布说明包含中文与 English 章节，之后只有一个精确名为 `## 下载` 的下载段和一张双语表，表中继续使用 `DevKit-portable.exe` 与 `DevKit-win-x64.zip`。

#### Scenario: CI 刷新下载表

- **WHEN** 发布流水线在 Release 附件生成后刷新下载信息，且说明中存在唯一、顺序正确的下载表 marker 对
- **THEN** 只有 marker 内的双语下载表被替换，marker 外的中文、English 与人工维护内容逐字保留。

#### Scenario: Release marker 无效

- **WHEN** Release 说明中的下载表 marker 缺失、重复或顺序错误
- **THEN** 发布流水线明确失败且不重写整篇说明，维护者可修复模板后重试。

#### Scenario: 应用内查看发布说明

- **WHEN** 应用发现符合条件的新版本并显示该 Release 的发布说明
- **THEN** 更新界面同时展示中文与 English 两个章节，不因当前应用语言隐藏或删除其中一个章节，并继续识别唯一的 `## 下载` 段。

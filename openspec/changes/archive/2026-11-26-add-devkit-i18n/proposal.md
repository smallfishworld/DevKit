## Why

DevKit 当前以中文界面和中文文档为主，英语用户无法完整理解工具入口、设置、错误提示、原生窗口文案与发布说明。应用需要先建立一套可持续维护的中英文能力，同时保持默认中文和现有调试会话的连续性。

## What Changes

- 在设置中增加 `简体中文（zh-CN）` 与 `English（en）` 语言选项；默认使用中文，切换立即生效并持久化，且不重载工作台、不关闭标签、不打断串口、终端、网络或传输会话。
- 覆盖全部 DevKit 自有工具界面文案，包括渲染进程界面以及主进程创建的原生窗口、对话框和通知中的应用自有文案；终端输出、设备/网络报文、用户数据、第三方页面及外部工具内容保持原样。
- 新增完整的 `README.en.md`，并与中文 `README.md` 在显眼位置互相链接。
- 同一 GitHub Release 的发布说明同时提供中文与 English 章节，只保留一张双语下载表，并继续保留精确标题 `## 下载`，兼容已部署版本的更新读取逻辑。
- 发布 CI 仅更新受标记保护的下载表区段，不覆盖人工维护的中英文发布说明；应用内更新界面展示同一 Release 的两个语言章节。

## Capabilities

### Modified Capabilities

- `workbench`：增加应用语言切换、DevKit 自有界面完整中英文本地化，以及双语 README 与 Release 契约。

## Impact

涉及共享本地化资源、用户设置持久化、渲染进程全部内置工具、主进程原生文案、更新界面、README、Release 工作流与相关测试。不会改变终端、设备、网络、文件或协议数据的编码和内容。

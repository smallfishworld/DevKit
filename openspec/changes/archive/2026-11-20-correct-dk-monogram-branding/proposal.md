## Why

用户用新附件明确纠正应用图标：最终要求是蓝紫渐变的 DK 连体标识，以及深紫色圆角底板上的应用图标。现行统一标识规范需要与这次明确纠正保持一致。

## What Changes

- 将统一标识要求更新为 DK 字母连体、清晰的 D 形负空间与蓝紫渐变；标题栏使用无底板标识，应用图标使用深紫圆角底板。
- 保留深浅主题与版本入口、Windows 打包与运行时图标一致、单源派生小尺寸资源三个验收场景。
- 保留现有 Windows 应用身份和 EXE、包内运行时资源的实际产物核验要求。

## Scope and Status

- 影响的现行能力仅为 `workbench`，同步 `openspec/specs/workbench/spec.md` 的「统一应用标识」要求。
- 本变更记录用户纠正后的需求；资产、接入与验证任务待实施负责人逐项确认，不将尚未完成的测试记为通过。
- 既有 Module Core 归档保留历史原貌；本次不扩展工作台版式、功能或发布流程，不宣称 macOS/Linux 已完成实测。

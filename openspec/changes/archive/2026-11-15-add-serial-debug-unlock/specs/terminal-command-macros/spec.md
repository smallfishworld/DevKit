## ADDED Requirements

### Requirement: 串口快捷命令解锁 Debug

串口编辑器 MUST 支持添加使用本地设备配置的「解锁 Debug」步骤。快捷命令 MUST 在设备确认成功后才执行后续步骤，导出 MUST 只携带配置引用。

#### Scenario: 解锁后查询版本

- **WHEN** 用户在已连接的串口回放「解锁 Debug → 查询版本」，且设备确认解锁成功
- **THEN** 工作台在该连接上发送版本查询。

#### Scenario: 无法回放解锁宏

- **WHEN** 在非串口终端运行解锁宏，或串口缺少该宏引用的设备配置
- **THEN** 工作台提示原因，在任何步骤产生串口或终端输出之前中止。

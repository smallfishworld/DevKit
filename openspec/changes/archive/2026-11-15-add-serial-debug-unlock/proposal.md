# 串口快捷命令支持 OA 会话 Debug 解锁

## Why

公司设备的 Release 串口需要用 OA 登录后的业务网站换取解锁口令。重复切换应用和复制口令耗时，也容易把口令发到错误的连接。

## What Changes

- 在串口快捷命令中增加可配置的 Debug 解锁步骤，能在解锁确认后接续普通命令。
- 增加独立 OA 会话、公司取码适配和指定串口连接的解锁任务。
- 用本地模拟站点和串口验证。真实内网地址、接口字段和设备提示在公司内网配置与验收。

## Impact

- `terminal-command-macros` 新增串口专用步骤，影响编辑、导入导出与回放。
- `serial-terminal` 新增解锁事务的写入互斥、取消和口令审计行为。

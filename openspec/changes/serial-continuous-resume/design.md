# 设计

串口启动为共享 TerminalRuntime 指定 keepParsingWhenHidden，忽略显示可见性对输出派送的暂停操作，始终按接收顺序发送至现有 xterm。后台关闭 Chromium 定时器节流，隐藏标签由 xterm 内部 IntersectionObserver 暂停绘制。系统冻结时自然停止执行，恢复后沿用解析器和回滚，输出仍由解析完成 ACK 限流。

不在恢复时发送软复位、截取尾部、清屏或轮换日志。休眠前排空 RX、清屏审计边界、UTF-8 解码和日志失败处理沿用既有路径。1200ms 恢复标记窗口保留，用于标注驱动补交数据的时间不确定性。移除仅凭休眠时长触发的失步横幅。

代价是后台继续消耗解析 CPU。无硬件流控输入仍可能超过承载量，沿用显示溢出告警，不承诺无限吞吐。Windows 真机需测试最小化、锁屏、自动熄屏和手动睡眠，比较返回延迟、上翻稳定性、CPU、内存和接收序号。

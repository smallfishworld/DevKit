# 分屏（Split Panes）

## 目标

支持将任一工具标签分到左右两个分屏格并排使用，对齐 VS Code 的分栏体验。典型场景：左串口监视、右 SSH 调试；或左日志、右计算器。

## 范围

涉及 workbench 的标签分组模型、TabBar 参数化与双栏布局。只做左右两栏（不做任意网格/上下分屏）；主进程 IPC 与各工具面板组件零改动（面板本就以 panelId 隔离，双栏只是渲染端同时挂载两个组件实例）。

## 动机

- 全屏 4K 下单面板宽度大量剩余，串口 + SSH 并排是嵌入式调试的刚需。
- 现状单标签区在两个会话间来回切换，对照日志与操作时效率低。

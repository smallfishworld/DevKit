# 文本 / HEX 自动应答插件
这是一个独立的 DevKit API v1 插件，不依赖 OA、宿主内部源码或串口原生模块。

## 使用
在串口面板打开插件管理，导入本目录，创建配置实例，再将实例绑定到已连接的串口。选择自动监听后开始匹配；安装插件本身不开始监听。
文本模式按 CR/LF 完整行精确匹配，默认收到 PING 后回复 PONG 加 CRLF；可配置忽略大小写、换行和延时。HEX 模式按字节序列匹配，支持跨接收批次及一次数据多次命中，例如匹配 AA 01，回复 55 FE。HEX 模式的匹配和回复均须完整非空字节。
手动动作“发送配置的回复”可从界面或快捷命令调用。“清空协议缓存”不发送数据。
最多每次接收回复 32 次，缓存有上限，关闭插件会清理待发延时。

## 开发验证
`node test.cjs`
该测试在普通 Node 环境使用最小 SDK mock 运行，可独立于 DevKit 仓库维护。
独立进程和串口互斥由 DevKit 宿主的集成测试验证。

## 文件
- manifest.json：插件身份、配置结构和动作。
- index.cjs：插件逻辑。
- test.cjs：独立协议行为回归。

# 串口清屏、回滚、颜色和时间戳设计评审

## 背景
用户实测 DevKit v0.1.10 主分支：清空终端后仍能通过滚轮进入旧磁盘历史；自动回滚的磁盘文本无原始颜色且无视当前“时间戳”开关。

根因：`TerminalRuntime.resetOutput()` 只处理显示队列，`SessionHistory.tailPage()` 则始终可倒读全部 .log；`LogFormatter` 把 SGR/VT 等 ANSI 序列剥除并强制写入每行时间戳。这两套数据不应该作为同一个“终端回滚”无条件拼接。

## 开源参考

- **Tabby**：串口、终端 xterm/WebGL、可配置 scrollback、可独立保存输出。回滚格式跟随终端渲染器，日志文件不是天然可着色的屏幕快照。
  https://github.com/Eugeny/tabby
- **tio**：清屏（Ctrl-T l）、时间戳切换（Ctrl-T t）、文件日志开关（Ctrl-T f）是不同操作。
  https://github.com/tio/tio
- **Serial Studio**：Console 的 Clear 只清 console output；Show Timestamp、VT-100、ANSI Colors 是独立可视设置；Console Log 会移除 ANSI 后再写盘，说明其文本日志同样不能直接变成彩色终端回滚。
  https://github.com/Serial-Studio/Serial-Studio/blob/master/doc/help/Toolbar-Reference.md
- **Windows Terminal**：clearBuffer 明确区分 screen、scrollback、all；UI clear 不等于删除用户磁盘日志。
  https://learn.microsoft.com/windows/terminal/customize-settings/actions

## 本轮 P0/P1 修正

1. **清屏可视边界**。用户点击清屏时，立即将当前磁盘归档写入字节偏移标记为本次可视历史起点；不删除已有日志文件。窗口清屏后向上滚动不能看到清屏前的磁盘日志，直到新数据写入。
2. **上下文查询隔离**。`history:tail` 只读取上次用户清屏后的数据，`history:query`、日志导出和保存完整文件仍然允许查到清屏前内容。
3. **禁止空历史误触发**。在 xterm 最顶部向上滚动时，先检查显示历史是否存在；清屏后若没有新数据，不弹出磁盘历史覆盖层。
4. **显示时间戳与主题**。磁盘文本行中的 `[YYYY-MM-DD HH:mm:ss.mmm]` 是归档元数据。历史层按当前“时间戳”开关决定是否显示，只显示和实时串口一致的 `[HH:mm:ss.mmm]`，并使用当前终端主题的前景/背景色和较淡时间戳色。纯文本旧日志**无法恢复设备曾经输出的 SGR 真彩色**。

## P2：真正完整的彩色、无缝、可无限回滚的正确架构（尚未实现）

不要从已剥离 ANSI 的 `.log` 文件反推颜色，也不要把 ANSI escape 原文当可见文本或编造着色。

- **原始归档**：原封不动保存串口解码后的 VT/ANSI 字节流（或保留原始设备字节另作记录），独立于面向用户的 UTF-8 清洗文本日志；记录接收时间与递增偏移。采取分段、追加式文件，避免堆积到 JS 内存。
- **状态快照**：记录 SGR 前景/背景颜色（含 16/256 色和 RGB）、粗体、反色、VT 终端光标、自动换行及屏幕模式。可定期保存解析器检查点，避免用户翻旧记录时从文件开头重放所有控制码。
- **历史渲染**：由终端同一个 VT 解析器（或完整格式兼容的头无界/离屏解析器）生成只读可视行，分屏幕行或逻辑行按游标读取。不要把大量旧数据回放到实时 xterm 造成刷屏，也不要用普通文本 DOM 伪装成彩色终端。
- **清屏世代**：用户清屏时只更新当前可视历史起点，磁盘旧记录仍可从独立历史查询窗口打开。原生设备发送的 `CSI 2J`、`CSI 3J` 另按 VT 语义处理，不等于用户主动清屏。
- **稳定连续**：维护磁盘偏移/屏幕行序号与 xterm 可见行的映射，自动回滚只加载渲染器早于第一行的部分；避免当前旧版发生的重复、无颜色、跳到磁盘最新位置。
- **压测**：115200/921600 baud、大量 SGR/无换行/Unicode、跨批 ANSI、清屏与读写竞态、交错切屏和高亮查找。确保磁盘显示归档不会影响主采集日志回压。

## 兼容规则

- 新逻辑不修改既有 `.log` 文件、导出格式、日志查询结果。
- 对已经剥色的归档，颜色不可恢复；不能声称本轮解决了原始 SGR 历史着色。
- 不增加用户可见的配置项；用户已有时间戳和主题设置继续控制显示。
